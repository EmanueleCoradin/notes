# Personal explorations

A distinct space for topics unrelated to my PhD: philosophy, reading, history, culture, music, the outdoors, hobbies, and anything else worth understanding.

This is intentionally open-ended. I can add subfolders when a topic grows rather than committing to a taxonomy now. A note can link to [[Physics/index|Physics]], [[Computing/index|Computing]], or [[Concepts/index|Concepts]] whenever an unexpected connection emerges.

**Public-notes reminder:** this vault is in a public GitHub repository and may appear on the note-site. Personal here means independent interests, **not private** diary entries, sensitive information, or restricted documents. Such material belongs in a separate private location.
