# Literature

One Markdown note per source, using [[Templates/Literature Note|Literature Note]] as a starting point. Keep the paper's bibliographic record and PDF in Zotero or the existing literature library; this folder contains the understanding extracted from the reading.

A useful literature note captures the paper's question, approach, key claims, limitations, relevant page or section references, your interpretation, and open questions. Link its reusable physics to notes in [[Physics/index|Physics]] or [[Concepts/index|Concepts]].
